## 定位

覆盖 **A股 / 港股 / 美股** 的多源数据量化选股引擎。数据层以东方财富公开行情为主通道，K线多通道自动容灾（push2his 多节点 → 腾讯公开K线 → 新浪美股全历史），实时行情主/延迟节点自动切换，单通道不可达不影响结果产出；另含估值、资金流、板块与缓存并发层。

内置 **17 种真实可审计策略**，全部为确定性计算，同数据必同结果，无模型猜测、无编造补全。每只入选标的输出策略画像（各策略维度得分概览，解释"为什么入选"）与支撑/压力位，随文本 / JSON / HTML 报告展示。

- **组合筛选**：并集 / 交集 / 加权三种模式，权重可自定义；支持多周期验证。
- **自进化权重**：基于策略表现档案库的**真实历史表现**自动生成加权模式权重，如实标注"历史统计，不代表未来收益"。
- **自然语言意图解析**：人性化入口，用户说"帮我选低估值高股息"可解析为策略组合 + 市场 + 组合模式建议（确定性规则映射）。
- **数据质量如实标注**：报告【数据质量】段显式量化偏差——候选池覆盖率、财务报告期滞后天数、估值口径。
- **三市场能力边界如实**：A股/港股/美股三市场真实可用（技术面 / 估值 / 财务策略），无公开数据则如实判定不通过。

## 特性

- 🌐 **三市场覆盖** — A股 / 港股 / 美股，多源数据交叉验证
- 📊 **17 种内置策略** — 量价形态、技术指标、基本面估值、成长质量、趋势动量全覆盖
- 🔀 **组合筛选** — 并集 / 交集 / 加权打分 三种组合模式自由切换
- 📈 **多周期验证** — 日 / 周 / 月 多周期共振，提高信号可靠性
- 🎯 **自由入口** — 可直接指定策略编号，也可描述需求由系统推荐策略
- 🧠 **自进化权重** — 基于真实历史表现自动生成加权模式权重
- 💬 **自然语言意图解析** — 确定性规则映射，人性化入口
- ⚡ **即插即用** — 开箱即用，仅依赖标准库，零外部配置

## 快速开始

本技能为 Skill 格式，在支持 OpenClaw / Codex CLI / ChatGPT / Claude Code / DeepSeek / Gemini / Kimi 的环境中加载后即可使用。

```bash
# 示例触发词
- 用S06和S07策略筛选A股
- 找MACD底背离的港股
- 高股息+低估值，两市都看
- 用综合评分模型推荐股票
```

```bash
# A股完整能力（含基本面/资金流策略）
python run_screening.py --market A股 --strategies S01,S05,S07 --top 20

# 加权组合 + 自定义权重
python run_screening.py --strategy-mode weighted --weights "S01=0.15,S05=0.25,S07=0.20" --top 20

# 自进化权重（基于档案库真实历史表现生成加权权重）
python run_screening.py --auto-weights --top 20

# 自然语言选股意图解析（人性化入口）
python intent.py "帮我选低估值高股息"

# 港股/美股（三市场全功能：技术面/估值/财务策略真实可用）
python run_screening.py --market 港股 --strategies S01,S05,S08 --top 20
python run_screening.py --market 美股 --strategy-mode weighted --weights "S01=0.2,S05=0.3,S08=0.2" --top 20
```

## 项目结构

```text
stock-selecter-pro/
├── SKILL.md                    # 技能主文档
├── references/                 # 安装指南 / 规范对齐说明
├── scripts/
│   ├── config.py               # 全策略参数配置 + 多市场参数 + 性能参数
│   ├── run_screening.py        # 多市场主入口（--market A股/港股/美股/全部）
│   ├── intent.py               # 自然语言选股意图解析（确定性规则映射）
│   ├── data/                   # 数据层（A股/港股/美股/财务/资金流/板块/HTTP容灾）
│   ├── indicators/             # 技术指标库（MA/EMA/MACD/RSI/BOLL/ADX/ATR）
│   ├── strategies/             # 策略层（全部真实代码，可审计）
│   ├── composers/              # 策略组合引擎（union/intersection/weighted）
│   ├── reports/                # 报告生成层（text / json / 自包含交互式HTML）
│   ├── cache/                  # 缓存层（KlineCacheManager 内存+文件双层缓存）
│   └── archive/                # 策略表现档案库（可选模块）
└── LICENSE                     # MIT 开源许可协议
```
