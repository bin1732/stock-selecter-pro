# 多策略量化筛选

覆盖 A股/港股/美股 的多源数据量化选股引擎，内置 17 种选股策略，支持并集/交集/加权组合筛选与多周期验证。

## 核心策略

| 编号 | 策略名称 | 思路 |
|------|----------|------|
| S01 | 红肥绿瘦 | 阳线数量与幅度占优，上涨动能强 |
| S02 | 上涨波段 | 处于明确上升趋势中 |
| S03 | 回调缩量 | 上涨趋势中回调缩量，蓄力再上 |
| S04 | 横盘调整 | 长期横盘整理，变盘窗口临近 |
| S05 | MACD底背离 | 价格创新低但MACD未跟随，底部信号 |
| S06 | 高股息 | 高股息率+稳定分红，防御型配置 |
| S07 | 低估值 | PE/PB/PS 等多维度估值分位筛选 |
| S08 | 放量突破 | 成交量放大突破关键压力位 |
| S09 | 趋势分析 | 多周期趋势共振筛选 |
| S10 | 布林带下轨 | 触及布林带下轨，超跌反弹候选 |
| S11 | 筹码分析 | 筹码集中度与获利比例分析 |
| S12 | 现金流筛选 | 经营现金流与净利润质量筛选 |
| S13 | ROE选股 | 高ROE + 稳定增长的优质公司 |
| S14 | 费雪成长 | 成长股筛选，营收利润双增 |
| S15 | 海龟策略 | 趋势跟踪，突破20日/55日高低点 |
| S16 | 动量策略 | 相对强弱排序，强者恒强 |
| S17 | 综合评分 | 多维度加权综合打分 |

## 功能特性

- **三市场覆盖**：A股、港股、美股，多源数据交叉验证
- **17种内置策略**：量价形态、技术指标、基本面估值、成长质量、趋势动量全覆盖
- **组合筛选**：支持并集（满足任一）、交集（全部满足）、加权打分三种组合模式
- **多周期验证**：日/周/月多周期共振，提高信号可靠性
- **自由入口**：可直接指定策略编号，也可描述需求由系统推荐策略
