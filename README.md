# stock-selecter-pro

**多策略量化筛选** — 覆盖 A股 / 港股 / 美股 的多源数据量化选股引擎

</div>

## 特性

- 🌐 **三市场覆盖** — A股 / 港股 / 美股，多源数据交叉验证
- 📊 **17 种内置策略** — 量价形态、技术指标、基本面估值、成长质量、趋势动量全覆盖
- 🔀 **组合筛选** — 并集 / 交集 / 加权打分 三种组合模式自由切换
- 📈 **多周期验证** — 日 / 周 / 月 多周期共振，提高信号可靠性
- 🎯 **自由入口** — 可直接指定策略编号，也可描述需求由系统推荐策略
- ⚡ **即插即用** — 开箱即用，零配置启动

## 核心策略

| 编号 | 策略 | 类型 | 说明 |
|------|------|------|------|
| S01 | 红肥绿瘦 | 量价形态 | 阳线数量与幅度占优，上涨动能强 |
| S02 | 上涨波段 | 趋势 | 处于明确上升趋势中 |
| S03 | 回调缩量 | 量价形态 | 上涨趋势中回调缩量，蓄力再上 |
| S04 | 横盘调整 | 形态 | 长期横盘整理，变盘窗口临近 |
| S05 | MACD底背离 | 技术指标 | 价格创新低但MACD未跟随，底部信号 |
| S06 | 高股息 | 基本面 | 高股息率 + 稳定分红，防御型配置 |
| S07 | 低估值 | 基本面 | PE / PB / PS 多维度估值分位筛选 |
| S08 | 放量突破 | 量价形态 | 成交量放大突破关键压力位 |
| S09 | 趋势分析 | 趋势 | 多周期趋势共振筛选 |
| S10 | 布林带下轨 | 技术指标 | 触及布林带下轨，超跌反弹候选 |
| S11 | 筹码分析 | 资金面 | 筹码集中度与获利比例分析 |
| S12 | 现金流筛选 | 基本面 | 经营现金流与净利润质量筛选 |
| S13 | ROE选股 | 基本面 | 高ROE + 稳定增长的优质公司 |
| S14 | 费雪成长 | 成长 | 成长股筛选，营收利润双增 |
| S15 | 海龟策略 | 趋势跟踪 | 突破 20日 / 55日 高低点 |
| S16 | 动量策略 | 动量 | 相对强弱排序，强者恒强 |
| S17 | 综合评分 | 组合 | 多维度加权综合打分 |

## 快速开始

本技能为 Skill 格式，在支持 OpenClaw / Codex CLI / ChatGPT / Claude Code / DeepSeek / Gemini / Kimi 的环境中加载后即可使用。

```
# 示例触发词
- 用S06和S07策略筛选A股
- 找MACD底背离的港股
- 高股息+低估值，两市都看
- 用综合评分模型推荐股票
```
